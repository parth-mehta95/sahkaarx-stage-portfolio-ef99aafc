# Implement HTTP Request/Response Handlers with Validation

## Task Brief
Build request handlers with input validation, error responses, and proper HTTP status codes in your capstone API.

## Scenario
Your API needs robust validation. Implement request handlers that validate input, return appropriate status codes, and handle errors gracefully.

## Deliverables
- Validation middleware or decorator
- Request/response handler with error handling
- Test cases for invalid inputs

## Success Criteria
- Rejects invalid input with 400 status
- Returns 200/201 for valid requests
- Logs validation errors clearly
