# Resolve Merge Conflicts Hands-On

## Task Brief
Intentionally create and resolve merge conflicts in capstone repo to build conflict resolution confidence.

## Scenario
Two team members edited the same file on different branches; merge them and resolve the resulting conflict.

## Deliverables
- Resolved merge conflict in capstone repo
- Conflict resolution documented in commit message

## Success Criteria
- Conflict markers removed and file merged cleanly
- Commit message explains resolution choice
