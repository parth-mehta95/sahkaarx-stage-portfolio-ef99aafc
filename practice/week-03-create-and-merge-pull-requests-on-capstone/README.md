# Create and Merge Pull Requests on Capstone

## Task Brief
Build multiple pull requests on your capstone repo, conduct peer reviews, and merge with clean commit history.

## Scenario
Your team requires all code changes via pull requests. Create feature PRs, request reviews, and merge them cleanly.

## Deliverables
- Three pull requests with descriptions
- Merged PRs in main branch

## Success Criteria
- All PRs have clear titles and descriptions
- Commits follow best practices
