# Refactor API Layer with Dependency Injection

## Task Brief
Apply constructor injection and service container patterns to decouple handlers, validators, and data access layers.

## Scenario
Refactor 2-3 core API handlers to use DI, reducing tight coupling and improving testability for your team.

## Deliverables
- Refactored handler classes
- Service container implementation
- Updated unit tests

## Success Criteria
- Handlers accept dependencies via constructor
- Service container resolves dependencies
- Tests pass with injected mocks
