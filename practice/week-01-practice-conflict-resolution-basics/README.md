# Practice Conflict Resolution Basics

## Task Brief
Simulate and resolve merge conflicts to prepare for collaborative branching workflows in week 2.

## Scenario
Two team members edited the same file; you must merge their changes and resolve conflicts to maintain code integrity.

## Deliverables
- Resolved merge conflict in capstone repository
- Documentation of conflict resolution process

## Success Criteria
- Conflict markers properly identified and resolved
- Final merged file is syntactically correct
