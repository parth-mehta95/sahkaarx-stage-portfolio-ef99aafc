# Create and Merge Feature Branches

## Task Brief
Build feature branches on capstone repo, simulate parallel development, and merge changes back to main.

## Scenario
Your team is developing two features in parallel; create separate branches, make commits, and merge them to main.

## Deliverables
- Two feature branches with commits
- Merged branches in main branch

## Success Criteria
- Branches created with clear names
- Clean merge history visible in log
