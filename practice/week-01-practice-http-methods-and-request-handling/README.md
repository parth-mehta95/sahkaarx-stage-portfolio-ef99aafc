# Practice HTTP Methods and Request Handling

## Task Brief
Implement basic HTTP endpoint handlers and understand request/response cycles in your capstone.

## Scenario
Your API needs to handle incoming HTTP requests. Implement handlers for GET and POST to demonstrate HTTP fundamentals.

## Deliverables
- HTTP request handler implementation
- Sample GET and POST endpoints
- Request/response logging mechanism

## Success Criteria
- Endpoints accept and parse HTTP requests
- Responses include proper HTTP headers
- Handlers follow consistent patterns
