# Practice Basic Git Commands Workflow

## Task Brief
Execute add, commit, push, pull operations on capstone repository to build hands-on proficiency.

## Scenario
Your code review partner needs to pull your latest changes; practice the full workflow of staging, committing, and pushing.

## Deliverables
- Five new commits with varied file changes
- Updated README with workflow examples

## Success Criteria
- All commits have clear, descriptive messages
- Changes are properly staged before commit
