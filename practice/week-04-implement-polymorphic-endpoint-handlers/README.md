# Implement Polymorphic Endpoint Handlers

## Task Brief
Build inheritance hierarchy and interface contracts for multiple resource types in your capstone API.

## Scenario
Your team needs to support multiple resource types (users, products, orders) with shared validation logic. Design polymorphic handlers using inheritance and interfaces.

## Deliverables
- Base handler interface and abstract class
- Concrete handlers for 3+ resource types
- Polymorphic request routing logic

## Success Criteria
- All handlers implement shared interface
- Method overriding works correctly
- Routing dispatches to correct handler
