# Document Branching Workflow in README

## Task Brief
Update capstone README with branching strategy, conflict resolution process, and team workflow guidelines.

## Scenario
Your team lead asks you to document the branching workflow so new members understand your version control process.

## Deliverables
- Updated README with branching guidelines
- Workflow diagram or step-by-step instructions

## Success Criteria
- README explains feature branch naming
- Conflict resolution steps documented clearly
